# 📚 AppShelf

**Русский** · [English](README.md)

Список приложений, установленных на телефоне: **название, пакет, откуда каждое и когда установлено**,
по алфавиту. Сохраните его в файл, а после сброса или на новом телефоне откройте снова: AppShelf покажет,
каких приложений не хватает, и откроет каждое в нужном магазине.

## Возможности

- **Все установленные приложения** по алфавиту «как в словаре» (регистр и Ё/Е не важны), с буквами-разделами
- **Источник** каждого: Google Play, F-Droid (и Droid-ify, Neo Store), Aurora Store, Obtainium, RuStore,
  GetApps, Galaxy Store, AppGallery, Amazon — или **APK-файл**, в том числе из какого приложения его открыли («APK · через Telegram»)
- **Дата установки**, версия и последнее обновление в карточке приложения
- **Поиск** по названию и пакету, **фильтр по источнику**, системные приложения по желанию
- **Сохранение списка** в JSON (для восстановления), Markdown (для чтения, например в Obsidian) или CSV (для таблиц), либо «Поделиться» текстом
- **Выбор, что попадёт в список**: «Выбрать приложения…» в окне сохранения — галочки, поиск и «выбрать все / снять все»;
  исключённые приложения не сохраняются, не отправляются и не попадают в автосохранение (то же — из карточки приложения)
- **Синхронизация WebDAV по расписанию**: Nextcloud, ownCloud, Яндекс Диск, NAS — каждый день, по выбранным дням недели
  или раз в N дней в заданное время, по желанию только по Wi-Fi; хранятся последние версии (по умолчанию 10);
  на новом телефоне список открывается прямо с сервера
- **Сохранение и экспорт** в одном окне: файл, «Поделиться», автосохранение, WebDAV, выбор приложений
- **Автосохранение**: выберите файл один раз (облачный диск, карта памяти…) — список будет перезаписываться в нём при каждом открытии
- **Режим восстановления**: откройте сохранённый список — видно, сколько приложений не хватает, можно показать только их и установить каждое из его магазина
- **Дизайн Material 3 с «жидким стеклом»**: полупрозрачные карточки поверх мягкого цветного фона, цвета подстраиваются
  под обои (Android 12+). Темы: стандартная, как в системе, AMOLED (чёрная), светлая, графит — нажатие на
  название «AppShelf» переключает на следующую, удержание возвращает стандартную

## Скачать

Готовые APK — на странице [Releases](https://github.com/Xtratter/appshelf/releases). Нужен Android 8.0 или новее.

## Разрешения

- `QUERY_ALL_PACKAGES` — без него на Android 11+ приложение видит лишь часть установленных приложений.
- `INTERNET`, `ACCESS_NETWORK_STATE` — только для синхронизации WebDAV и только с сервером, который вы укажете; больше ничего в сеть не уходит.
- `RECEIVE_BOOT_COMPLETED` — чтобы расписание синхронизации восстанавливалось после перезагрузки.

## Как это устроено

Всё берётся из `PackageManager` Android: даты — из `firstInstallTime` / `lastUpdateTime`, установщик и приложение,
из которого запустили установку APK, — из `getInstallSourceInfo()` (Android 11+).
Файлы пишутся через системный выбор файла (Storage Access Framework), поэтому разрешение на память не нужно.

```
app/src/main/java/io/github/xtratter/appshelf/
├── Apps.kt           ← чтение установленных приложений
├── Model.kt          ← AppInfo и Source (пакет установщика → магазин)
├── ListFile.kt       ← сортировка и файлы JSON / CSV / Markdown
├── WebDav.kt         ← небольшой клиент WebDAV (PUT, GET, PROPFIND, MKCOL)
├── Schedule.kt       ← когда следующая отправка
├── Sync.kt           ← будильник → отправка, при необходимости ждёт сеть; SyncDialog.kt — настройки
├── Store.kt          ← открыть приложение в его магазине
├── MainActivity.kt   ← список, сводка, фильтры, сохранение и режим восстановления
├── AppItemView.kt    ← строка списка (рисуется вручную для плавной прокрутки)
├── DetailsDialog.kt  ← карточка приложения
└── Ui.kt, Theme.kt   ← стеклянный дизайн и темы
```

## Сборка

```sh
./gradlew assembleRelease      # → release-сборка (R8), подписать через apksigner
./gradlew testDebugUnitTest    # тесты: источники, сортировка, форматы файлов, расписание
```

Нужны JDK 17 и Android SDK (платформа 35, build-tools 35.0.0). Библиотек нет.
