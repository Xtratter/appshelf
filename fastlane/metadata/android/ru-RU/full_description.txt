AppShelf хранит список установленных на телефоне приложений — название, пакет, версию, откуда каждое установлено и когда, — чтобы вернуть их все после сброса или на новом телефоне.

<b>Список</b>
<ul>
<li>Все приложения по алфавиту, с буквами-разделами и поиском по названию, пакету и вашим заметкам</li>
<li>Источник каждого приложения: Google Play, F-Droid, Aurora Store, Obtainium, RuStore, GetApps, Galaxy Store, AppGallery, Amazon — или APK-файл, вместе с приложением, из которого его открыли</li>
<li>Дата установки, версия, последнее обновление; фильтры по источнику; системные приложения — по желанию</li>
<li>Заметки и свои ссылки для скачивания (GitHub, Telegram, прямой APK) к любому приложению, плюс общий каталог ссылок</li>
<li>«Что изменилось»: установки и удаления по дням, сравнение с другим телефоном</li>
</ul>

<b>Сохранение</b>
<ul>
<li>Сохранить список в JSON, Markdown или CSV, поделиться текстом или автосохранять в файл при каждом запуске</li>
<li>Синхронизация по WebDAV по расписанию (например, Nextcloud, Яндекс Диск): папка для каждого телефона и несколько версий; пропущенная отправка догоняется позже</li>
<li>Копии APK приложений, которых больше нигде не взять, — в папку или на сервер</li>
<li>Сохранение и восстановление настроек самого AppShelf — в файл или на сервер, с паролем WebDAV или без</li>
</ul>

<b>Восстановление</b>
<ul>
<li>Откройте сохранённый список — видно, чего не хватает; ставьте каждое из его магазина, своей ссылки или копии APK — или все подряд</li>
<li>Обновления приложений из релизов GitHub</li>
</ul>

<b>Оформление</b>
<ul>
<li>Material 3 Expressive, темы: как в системе, светлая, тёмная, графит, AMOLED; прозрачность по желанию</li>
<li>Мягкие размытые края, отклик вибрацией, справка по удержанию на любой кнопке</li>
</ul>

Без рекламы, трекеров и аккаунтов. Сеть — только для того, что вы настроили сами: ваш сервер WebDAV, каталог ссылок и релизы GitHub.
