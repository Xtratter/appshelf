# История версий

**Русский** · [English](CHANGELOG.md)

## 1.1 — 2026-09-28

- Нажатие на название «AppShelf» в шапке переключает на следующую тему, удержание возвращает стандартную; подсказка показывает, какая тема включена

## 1.0.1 — 2026-09-28

- Кнопка «Автосохранение» в сводке больше не переносится и не обрезается: когда оно включено, на ней галочка ✓, а текст уменьшается, если не помещается
- Источники в сводке больше не разрываются между строками (например, «F-Droid» / «14»)

## 1.0 — 2026-09-28

Первая версия:
- Список установленных приложений по алфавиту, с буквами-разделами: название, пакет, источник и дата установки
- Определение источника: Google Play, F-Droid и его клиенты, Aurora Store, Obtainium, RuStore, GetApps, Galaxy Store, AppGallery, Amazon, APK-файл («через Telegram»), предустановленное
- Поиск, фильтр по источнику, системные приложения по желанию; карточка приложения с версией, датами и действиями
- Сохранение списка в JSON, Markdown или CSV, «Поделиться» текстом, автосохранение в выбранный файл при каждом запуске
- Режим восстановления: открыть сохранённый список, увидеть и установить недостающие приложения из их магазинов
- Дизайн Material 3 с «жидким стеклом» и пятью темами
