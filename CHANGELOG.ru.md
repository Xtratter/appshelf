# История версий

**Русский** · [English](CHANGELOG.md)

## 1.8 — 2026-09-30

- **Тема «Жидкое стекло» (эксперимент)** в духе iOS 26, Android 13+: верхняя панель — настоящее стекло: список виден сквозь неё и изгибается у скруглённых краёв, как в линзе, с лёгким размытием, цветными ореолами и яркими бликами по кромке; карточки преломляют яркий фон под собой, и при прокрутке преломление плывёт. Тема — в списке тем и в переключении нажатием на название; на старых Android выглядит как обычное стекло

## 1.7 — 2026-09-30

- **Установка APK прямо из AppShelf**: прямая ссылка на файл .apk скачивается (с прогрессом и отменой), проверяется, что в файле то самое приложение, и передаётся установщику Android. В первый раз AppShelf попросит разрешение «Установка неизвестных приложений» и продолжит сам, когда вы вернётесь
- **Одна точка входа — «Сохранение и восстановление»** на главном экране: сохранение (файл, «Поделиться», автосохранение, WebDAV, приложения в списке, ссылки для каталога) и восстановление (из файла или с сервера) в одном окне. Кнопка ⬇ и повторяющиеся пункты меню убраны
- В окне ссылки у полей есть подписи «Ссылка» и «Подпись»; если ссылку вставили в подпись — AppShelf подскажет

## 1.6 — 2026-09-30

- **«Где скачать»** в карточке приложения: свои ссылки для любого приложения — GitHub, GitLab, Codeberg, Telegram, 4PDA, сайт или прямая ссылка на .apk; ссылка из буфера обмена подставляется сама, удержание — изменить или удалить. Репозитории открываются на последнем релизе
- **Obtainium**: если он установлен, ссылки на GitHub / GitLab / Codeberg можно добавить в него — он установит приложение и будет его обновлять
- Свои ссылки не теряются: они сохраняются внутри каждого списка (JSON, CSV, Markdown с кликабельными ссылками) и общие для всех телефонов через «links.json» на сервере WebDAV; при открытии списка его ссылки добавляются к своим, побеждает более свежее изменение
- **Каталог ссылок** (меню): общий sources.json с GitHub — по умолчанию [Xtratter/appshelf-sources](https://github.com/Xtratter/appshelf-sources), адрес можно поменять. Скачивается целиком не чаще раза в день; свои ссылки всегда главнее
- **Режим восстановления**: у недостающего приложения со ссылкой в списке видно «GitHub ›», а в карточке — «Установить: GitHub» перед магазином
- Фильтр «APK без ссылки» — чтобы заполнить ссылки для приложений из APK-файлов
- **Сохранение и экспорт → Ссылки для каталога** — свои ссылки готовым sources.json для репозитория каталога

## 1.5 — 2026-09-30

- **Своя папка для каждого телефона на сервере WebDAV**: списки ложатся в «AppShelf/POCO F3/AppShelf_2026-09-30_135307.json»; имя папки задаётся в настройках WebDAV (по умолчанию — имя телефона), папка создаётся сама
- Открытие с сервера: сначала телефон («POCO F3 · 10 версий · последняя …»), потом версия; если телефон один — сразу его версии. Файлы прежних версий AppShelf из основной папки — в пункте «Другие файлы»
- **Пропущенная плановая отправка всё равно выполнится**: она остаётся «в долгу», пока отправка не пройдёт успешно, — после перезагрузки, без сети или VPN, при отказе сервера или если будильник не сработал. Фоновая проверка раз в несколько часов (и каждый запуск приложения) отправит список при первой возможности; в сводке видно «плановая отправка отложена»

## 1.4 — 2026-09-30

- **Сохранение и экспорт** — все способы сохранить список в одном окне: в файл (JSON / Markdown / CSV), «Поделиться», автосохранение, синхронизация WebDAV и выбор приложений; у каждого пункта видно его состояние. Открывается кнопкой ⬇, кнопкой в сводке и из меню
- **Версии на сервере**: каждая отправка — отдельный файл с датой и временем («AppShelf-POCO F3_2026-09-30_135307.json»); сколько хранить — на выбор (по умолчанию 10, 1 — один файл, как раньше), более старые удаляются
- **Выход из восстановления**: когда установлено последнее недостающее приложение, AppShelf предлагает вернуться к своему списку; если не хватает ничего — в карточке одна кнопка «Вернуться к моему списку»; жест «назад» тоже выходит из восстановления
- «Открыть сохранённый список» спрашивает откуда: из файла или с сервера WebDAV

## 1.3.1 — 2026-09-30

- Если Android, VPN или файрвол не пускают AppShelf в сеть, синхронизация WebDAV так и пишет и подсказывает, где разрешить, — вместо «socket failed: ECONNREFUSED»
- При подключении перебираются все адреса сервера (IPv6 и IPv4), а не только первый
- Телефон называется торговым именем из прошивки («POCO F3»), если имя устройства в Android не задано, — в имени файла WebDAV и в сохранённых списках

## 1.3 — 2026-09-30

- **Синхронизация WebDAV** (меню → «Синхронизация WebDAV»): список отправляется на ваш сервер — Nextcloud, ownCloud, Яндекс Диск, NAS
- **Расписание**: каждый день, по выбранным дням недели или раз в N дней — в выбранное время; по желанию только по Wi-Fi
- Если в это время телефон был выключен или без сети, список отправится при первой возможности; расписание переживает перезагрузку
- Каждый телефон пишет свой файл («AppShelf-POCO F3.json»), так что новый телефон не затрёт список старого
- **Открыть список с сервера** — сразу в режиме восстановления, самые свежие сверху
- Кнопки «Проверить» и «Отправить сейчас»; в сводке видно время следующей отправки или последнюю ошибку
- Пароль хранится зашифрованным ключом Android Keystore

## 1.2.1 — 2026-09-28

- Кнопка «Только недостающие» в режиме восстановления больше не съезжает вниз и не обрезается (то же исправление — для кнопки «Автосохранение»)
- Когда все приложения из открытого списка установлены, так и написано — «Все приложения из списка установлены ✓», а не «Ничего не найдено»
- В сохранённом списке телефон подписан именем устройства, если оно задано в Android, например «POCO F3 (M2012K11AG)» вместо «Xiaomi M2012K11AG»

## 1.2 — 2026-09-28

- **Выбор, какие приложения попадут в список**: пункт «Выбрать приложения…» в окне сохранения открывает список с галочками, поиском и кнопкой «Выбрать все / Снять все» (она действует на найденные поиском)
- Выбор запоминается и действует на сохранение, «Поделиться» и автосохранение; в сводке видно, сколько приложений не включается, а в основном списке они полупрозрачные
- «Не включать в список» / «Включать в список» в карточке приложения

## 1.1 — 2026-09-28

- Нажатие на название «AppShelf» в шапке переключает на следующую тему, удержание возвращает стандартную; подсказка показывает, какая тема включена

## 1.0.1 — 2026-09-28

- Кнопка «Автосохранение» в сводке больше не переносится и не обрезается: когда оно включено, на ней галочка ✓, а текст уменьшается, если не помещается
- Источники в сводке больше не разрываются между строками (например, «F-Droid» / «14»)

## 1.0 — 2026-09-28

Первая версия:
- Список установленных приложений по алфавиту, с буквами-разделами: название, пакет, источник и дата установки
- Определение источника: Google Play, F-Droid и его клиенты, Aurora Store, Obtainium, RuStore, GetApps, Galaxy Store, AppGallery, Amazon, APK-файл («через Telegram»), предустановленное
- Поиск, фильтр по источнику, системные приложения по желанию; карточка приложения с версией, датами и действиями
- Сохранение списка в JSON, Markdown или CSV, «Поделиться» текстом, автосохранение в выбранный файл при каждом запуске
- Режим восстановления: открыть сохранённый список, увидеть и установить недостающие приложения из их магазинов
- Дизайн Material 3 с «жидким стеклом» и пятью темами
